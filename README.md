# Soumya Sharma · portfolio

A static site: `index.html` plus the two resume PDFs. It has no build step.

To publish on GitHub Pages:
1. Create a public repo named `Swizknife.github.io`.
2. Add it as a remote and push: `git remote add origin https://github.com/Swizknife/Swizknife.github.io.git`, then `git push -u origin main`.
3. The site goes live at https://swizknife.github.io a minute or two later. Add `#edge` or `#ai` to the link to open it on that track.
