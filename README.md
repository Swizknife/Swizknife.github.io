# Soumya Sharma · portfolios

Two static sites with no build step:
- `edge/`: Edge AI & Embedded Systems
- `ai/`: AI-ML

To publish on GitHub Pages:
1. Create a public repo named `Swizknife.github.io`.
2. Add it as a remote and push: `git remote add origin https://github.com/Swizknife/Swizknife.github.io.git`, then `git push -u origin main`.
3. The sites go live a minute or two later at https://swizknife.github.io/edge/ and https://swizknife.github.io/ai/. The root URL has no page; send each recruiter the link that matches the role.

The resume PDFs in each folder are copies from `C:\VSC\work\resume\`. Update them there, then copy them here.
