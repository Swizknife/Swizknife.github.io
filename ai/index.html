MSME Policy Assistant

NS Apps Innovation · 2026 · knowledge graph + RAG

View code ↗
task
question answering with citations, Bihar MSME policy
retrieval
Google OKF graph · BGE-M3 dense + sparse · Qdrant · bge-reranker-v2-m3
serving
FastAPI + React · Ollama, fully local

Approach

Two tiers. A Google Open Knowledge Format graph of 249 concepts and 311 edges answers exact-fact questions directly, with no LLM call.

Open questions go through hybrid dense and sparse retrieval, rank fusion and a cross-encoder reranker. A coverage check declines to answer when the retrieved evidence is thin, instead of letting the model guess.

Amazon ML Challenge 2026

Business entity resolution · led a 3-member team, gemma_gals

View code ↗
task
match 1.7M businesses against ~10M noisy records
models
two-stage LightGBM (73 pair features) · mmBERT-small 140M cross-encoder
compute
12-thread laptop · Kaggle GPUs for fine-tuning

Approach

Multi-key blocking produces candidate pairs. A two-stage LightGBM cascade on 73 pair features cuts them from about 300 to 5.8 per entity while keeping recall high.

The pairs the cascade is unsure about go to a multilingual mmBERT-small cross-encoder, fine-tuned on Kaggle GPUs, which re-scores them.

Yoda: Multimodal Robot Backend

NS Apps Innovation · 2026 · vision + voice on an NVIDIA DGX Spark

Company project · code not public
task
see, recognise and answer people at a desk robot, on-prem
vision
RTMO-s pose → YuNet → SFace → FER+ · ONNX Runtime, PyTorch-free
voice
Silero VAD → faster-whisper int8 → wake phrase → Qwen3-VL-8B
compute
Grace CPU, ARM64 · no cloud

Approach

An asyncio FastAPI server accepts JPEG frames with a 202 and a drop-oldest queue, so the robot never waits for inference. Face ID is open-set: below a cosine of 0.363 a person stays UNKNOWN. Waves are detected from body keypoints.

Audio streams over an authenticated WebSocket. Silero VAD cuts it into sentences (0.3 s pre-roll, 0.7 s pause). Only sentences that start with “Hey Yoda” go on to Qwen3-VL-8B, which answers about the live frame. Everything else is dropped in memory and never written to disk. A Pydantic allow-list decides which commands can reach the hardware.

Nanopore Event Classifier

Research under Dr. Naren Das · BIT Mesra · 2026 – present

Lab research · ongoing
task
detect, fit and classify translocation events in nanopore current traces
data
440 recordings, 3.1 GB · 3,150 synthetic events
split
held-out recording day

Approach

A 17-module Python pipeline: rolling-median baseline, noise estimation, threshold + hysteresis detection, AdaBoost event fitting, and PSD noise features with PLS.

The classifier is scored on an independent recording day and compared against a cross-session baseline, not a random split.

Evaluation

MetricValueData
Balanced accuracy0.84Independent test day, vs 0.55 cross-session baseline
Shape accuracy92–100%3,150 synthetic events, ≥4× rise time
